# Delay Order Validation

A Work Order Approval & Delay Validation System consisting of:
- **Mobile Application**: For Approvers/BDEs to review, approve, disapprove, delay, and cancel requests.
- **Web Dashboard**: For Dispatchers to submit and monitor work order approval requests in real time.
- **Backend API & Database**: Centralized data management, authentication, role-based access control, and real-time synchronization.

## Structure
- `/web` - Dispatcher Web Dashboard
- `/mobile-android` - Native Android Mobile Application (Gradle 8.14.3)
- `/backend` - Database Schema & Node.js API Server
